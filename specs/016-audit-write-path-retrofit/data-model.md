# Data Model: Audit Write Path Retrofit

## Audit Event

Existing append-only entity in `audit.audit_events`.

Fields:

- `id`: UUID primary key, generated by database.
- `organization_id`: nullable UUID. Null only for already-documented no-organization auth/bootstrap cases.
- `actor_user_id`: nullable UUID.
- `actor_api_key_id`: nullable UUID.
- `action`: non-null text in `<resource>.<verb>` form.
- `resource_type`: non-null text.
- `resource_id`: nullable UUID.
- `before`: nullable JSONB, deeply redacted before insert.
- `after`: nullable JSONB, deeply redacted before insert.
- `transport`: non-null text enum, one of `web`, `api`, `cli`, `system`.
- `source_ip`: nullable text.
- `created_at`: non-null timestamptz, database default.

Validation rules:

- `transport` is required for every `record()` call and every stored row.
- `source_ip` is null for `system` events and may be null for non-system events where no network origin is available.
- `before` and `after` never persist known secret keys (`password_hash`, `key_hash`, `token`, `raw_token`, `jwt`) unredacted.
- No application code updates or deletes audit event rows.

## Audit Context

Value object threaded into audited application services.

Fields:

- `transport`: `web` | `api` | `cli` | `system`.
- `sourceIp`: string or null/undefined.

Validation rules:

- Defaults may be used only where the existing service is already known to be web/session-originated.
- API key paths pass `api` when invoked from authenticated API-key context.
- System jobs pass `system` and no actor/source IP.

## Action Verb Vocabulary

Reference table documented in the Audit & Compliance contract.

Canonical verbs:

- `created`
- `updated`
- `deleted`
- `revoked`
- `reparented`
- `shared`
- `accepted`
- `login`
- `logout`
- `login_failed`
- `synced`
- `pruned`

Each verb has a UI color token/category. Every shipped `action` string must use a verb from this list.
